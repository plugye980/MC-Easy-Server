# MCES

**MC Easy Server** — 친구들끼리 여는 마인크래프트 서버 간편 설치·관리 앱

친구들끼리 마인크래프트 서버를 여는 데 필요한 일을 한 앱에서 처리합니다.
플러그인 서버(Paper), 모드 서버(Forge 기본 · Fabric 선택), 바닐라 서버를 만들 수 있고, Java 준비, 최적화, 친구 접속 주소, 플러그인·모드 설치, 백업까지 앱이 맡습니다.

설치 마법사처럼 단계를 넘기는 방식이 아닙니다. Docker Desktop처럼 **한 화면**에서 서버를 추가·삭제·관리합니다. 왼쪽에 서버 목록이 있고, 오른쪽에서 고른 서버를 다룹니다.

## 실행

```bash
npm install
npm start          # 개발 실행
npm test           # 테스트
npm run dist:win   # Windows 설치 파일 + 포터블 exe (dist/)
```

## 데이터 위치

서버, Java 런타임, 백업, 터널 프로그램은 모두 **한 폴더 안**에 만들어집니다. 시스템에는 아무것도 설치하지 않습니다.

| 실행 방식 | 위치 |
| --- | --- |
| 개발(`npm start`) | `./data` |
| 설치판 (Windows) | `%LOCALAPPDATA%\MCES\data` |
| 설치판 (macOS·Linux) | 사용자 앱 데이터 폴더의 `data/` |
| 포터블 exe | exe 옆 `MCEasyData/` |

설치판 데이터는 설치 폴더 밖에 둡니다. 설치 프로그램은 업데이트·제거 때 설치 폴더를 통째로 지우기 때문입니다.
새 버전 설치 파일을 그냥 실행하면 서버가 그대로 유지됩니다. 예전 버전(실행 파일 옆 `data/`)의 데이터는 설치 과정에서 새 위치로 옮겨집니다.
포터블 exe는 새 exe를 같은 폴더에 덮어쓰면 됩니다.

```
data/
  servers/<id>/      서버 폴더 (server.jar, world, plugins|mods …)
  runtimes/java-21/  앱이 받은 Java (Adoptium Temurin JRE)
  backups/<id>/      월드 백업 zip
  tools/playit/      playit.gg 에이전트
  servers.json       서버 목록·설정
```

## 기능

### 서버를 만들기 전에 확인하는 것
- **Java 자동 감지·설치**: 고른 마크 버전에 필요한 Java 버전을 Mojang 메타데이터로 확인합니다(1.20.5 이상은 Java 21, 1.18~1.20.4는 17 등). 필요한 Java가 없으면 Adoptium에서 받아 `runtimes/`에 풉니다.
- **PC 사양 확인**: 전체 RAM을 읽어 서버 메모리를 추천합니다(예: 16GB → 6GB). 슬라이더에도 추천값이 표시됩니다.

### 서버를 만들 때
1. 종류 선택: 플러그인 서버(Paper), 모드 서버(Forge 기본 · NeoForge · Fabric), 바닐라 서버, 하이브리드 서버(Arclight · 플러그인과 Forge 모드를 함께)
   - 모드 서버는 **Forge가 기본**이고 Fabric을 고를 수도 있습니다. Forge는 설치 프로그램(`--installServer`)으로 라이브러리를 받아 설치하고, 설치된 인자 파일(`@libraries/.../unix_args.txt`, 구버전은 forge jar)로 실행합니다
2. 버전 선택: 기본값은 최신 안정 버전
3. 기본 설정: `server.properties`를 직접 보여주지 않고 난이도, 게임 모드, 최대 인원, PVP, 화이트리스트 등을 풀어서 설명합니다
4. EULA 동의: 한 줄 설명과 체크박스
5. 최적화 자동 적용
   - Aikar's flags(G1GC JVM 옵션). 12GB 이상이면 큰 힙용 값을 씁니다. Java 21 이상에서 없어진 옵션은 넣지 않습니다
   - `server.properties`: 할당 메모리에 맞춘 view-distance와 simulation-distance, network-compression-threshold
   - Paper: `paper-world-defaults.yml`, `spigot.yml`, `bukkit.yml`에 추천값을 넣습니다. 이 파일들은 첫 실행 때 생기므로, 생긴 뒤 주석을 유지한 채 값만 바꿉니다
   - Forge: ModernFix, FerriteCore를 함께 설치합니다
   - Fabric: Fabric API, Lithium, FerriteCore를 함께 설치합니다

### 맵
- **맵 수동 설정**: 월드 유형(기본 · 평지 · 큰 바이옴 · 증폭), 시드, 구조물 생성 여부를 정할 수 있습니다. 평지는 바이옴과 층(블록·두께)을 직접 쌓을 수 있습니다. 고전 평지에서 시작하며, 예를 들어 평원 바이옴에 기반암 1칸과 물 50칸을 쌓으면 물 세상이 됩니다.
- **다른 맵 가져오기**: 싱글플레이 저장 폴더(level.dat가 있는 폴더)나 그 폴더를 압축한 zip을 서버 월드로 씁니다. 맵에 저장된 마인크래프트 버전을 읽어서, 서버보다 새 버전이면 경고합니다.
- 이미 만든 서버는 설정 탭의 "맵"에서 다른 맵으로 바꾸거나, 새 설정으로 월드를 다시 만들 수 있습니다. 두 경우 모두 현재 월드를 먼저 백업합니다.

### 서버를 운영할 때
6. **터널 자동 연결**: 서버가 켜지면 앱이 playit.gg 에이전트를 내부에서 실행하고, 받아온 접속 주소를 상단에 **복사 버튼**과 함께 표시합니다. 첫 실행 때는 브라우저에서 한 번 승인해야 합니다. 포트포워딩이 되는 환경이라면 설정 탭의 **UPnP 포트 열기**를 대신 쓸 수 있습니다.
7. **접속 상태 확인**: 두 가지를 점검해 상태 점으로 보여줍니다(통과 = 코발트, 실패 = 어두운 자주). "서버 응답"은 로컬 Server List Ping, "외부 접속"은 mcsrvstat.us 외부 점검입니다.
8. **Modrinth 검색·원클릭 설치**: 현재 서버 종류와 버전에 맞는 것만 보여줍니다. 다운로드순(기본) · 관련도순 · 최근 업데이트 · 최신 등록으로 정렬하고, 아래 페이지 버튼으로 계속 넘겨 볼 수 있습니다. Paper는 paper/spigot/bukkit 플러그인, Fabric은 서버에서 도는 모드, 바닐라는 데이터팩입니다.
8-1. **파일로 직접 추가**: Modrinth에 없는 플러그인·모드는 플러그인(모드) 탭에서 "파일에서 추가"를 누르거나 파일을 끌어다 놓으면 됩니다. 파일을 넣으면 두 단계로 확인합니다.
   - 같은 파일이 Modrinth에 있으면 Modrinth 설치와 똑같이 관리합니다. 업데이트와 호환성 검사도 됩니다.
   - Modrinth에 없으면 파일 안의 정보를 읽습니다. 플러그인은 `plugin.yml`·`paper-plugin.yml`, 모드는 `fabric.mod.json`입니다. 여기서 이름, 버전, 지원하는 마인크래프트 버전, 빠진 의존성을 확인하고, 서버를 업데이트하기 전에 호환성을 경고합니다
   - 서버 종류가 다른 파일(모드 서버에 넣은 플러그인 등)은 넣지 않습니다. 버전만 맞지 않는 파일은 넣되 꺼 둡니다
   - 폴더에 직접 복사한 파일도 같은 방식으로 인식합니다
8-2. **모드팩 넣기**: 모드 서버(Forge · NeoForge · Fabric · 하이브리드)의 모드 탭에서 "파일에서 추가"나 끌어다 놓기로 모드팩 파일을 넣을 수 있습니다.
   - CurseForge 모드팩 zip(`manifest.json` + `overrides/`): 목록의 모드를 CurseForge에서 받아 `mods/`에 넣고, `overrides/` 안의 `config`·`kubejs` 등은 서버 폴더에 그대로 풉니다
   - Modrinth 모드팩(`.mrpack`): 서버에서 쓰지 않는 파일은 받지 않고, `overrides/`와 `server-overrides/`를 풉니다
   - CurseForge 목록에 섞인 zip은 `mods/`에 두지 않습니다. 데이터팩은 월드의 `datapacks/`로 옮기고, 서버가 쓰지 않는 리소스팩·셰이더는 건너뜁니다. `mods/` 폴더에 남은 zip은 모드 목록에 나오지 않습니다
   - 모드팩의 로더나 마인크래프트 버전이 서버와 다르면 경고합니다. 받지 못한 모드(제작자가 외부 배포를 막은 모드 등)는 알림으로 알려 줍니다
   - 접속하는 쪽 전용 모드(Sodium 등)가 섞여 서버가 화면 코드(`org.lwjgl.*`, `net.minecraft.client.*`)를 찾다 멈추면, mods 폴더를 살펴 원인 모드를 찾아 알려 줍니다. 알림의 "이 모드 끄고 다시 켜기"로 바로 끌 수 있습니다(자동으로 끄지는 않습니다)
   - 이 서버에서 돌지 않는 파일(NeoForge 서버의 Fabric 전용 jar 등)은 "필요 모드"를 띄우지 않고, Forge·NeoForge 서버에는 Fabric API를 이름으로 설치하지 않습니다. 서버에만 Forgified Fabric API가 들어가면 접속할 때 `registries with unknown keys`로 끊깁니다
   - 접속하던 사람이 게임에 들어오기 전에 끊기면, 서버와 접속하는 쪽의 모드가 다를 수 있다고 알려 줍니다
   - 넣는 동안 다른 화면에 갔다 와도 진행 막대가 이어지고, 끝날 때까지 같은 서버에 다른 파일은 넣지 않습니다
   - 설치된 목록은 이름 거르기 · 상태(켜짐 · 꺼짐 · 확인 필요) 거르기 · 40개씩 쪽 나누기로 수백 개도 다룰 수 있습니다
   - NeoForge 1.20.2~1.20.4 모드(`mods.toml`), 문법이 느슨한 `mods.toml`, 접속하는 쪽 전용 의존성(`side="CLIENT"`), jar 안에 묶인 라이브러리(jar-in-jar)도 바르게 판단해 "NeoForge 모드 아님"·"필요 모드"를 잘못 띄우지 않습니다
   - 지원 범위가 `[1.21,1.21.1)`처럼 좁게 적혀 있어도 같은 1.21 계열이면 "호환 안 됨"이 아니라 회색 "확인 필요"로 표시합니다. 마인크래프트 버전 없이 NeoForge 버전만 적은 모드는 NeoForge 버전에서 마인크래프트 버전을 읽습니다
   - 모드 탭의 "설치됨"과 "○○에서 찾기"는 고른 쪽 목록만 보여 줍니다
9. **의존성 자동 설치**: 필수(required) 의존성을 재귀적으로 함께 설치합니다. Fabric 서버라면 **접속용 mods.zip을 내보낼 수 있습니다.** 접속하는 쪽에 필요한 모드 jar를 그대로 묶은 파일이라, 압축을 풀어 `.minecraft/mods`에 넣으면 됩니다. 클라이언트에서 쓸 수 없는 서버 전용 모드는 빠집니다.
10. 켜기/끄기/다시 켜기, 삭제, 업데이트 버튼
11. **접속자 목록**: 클릭으로 강퇴, OP, 화이트리스트 추가, 차단을 할 수 있습니다. 서버 본체의 로그인·연결 끊김 줄로 감지해서, 플러그인이 입장 문구를 바꿔도 바로 반영됩니다
12. **성능 표시**: TPS·메모리·CPU 게이지와 메모리 사용량 그래프.
   - 메모리는 서버 JVM에 넣은 작은 측정 에이전트(`mces-agent.jar`, 소스는 `agent/`)가 2초마다 기록하는 현재 힙 사용량입니다. 최적화 옵션(-Xms=-Xmx, AlwaysPreTouch) 때문에 프로세스 메모리로는 늘 최대치로 보이고, GC 로그는 큰 힙에서 GC가 드물어 값이 거의 바뀌지 않습니다. 그래서 GC 로그는 보조로만 씁니다
   - CPU는 PC 전체 대비 비율입니다
13. **자동 백업**: 정해진 간격마다, 그리고 서버를 끌 때 월드를 백업합니다. 백업 중에는 `save-off` → `save-all flush` → zip → `save-on` 순서로 진행합니다. 복원 버튼을 누르면 지금 월드를 "복원 전" 백업으로 먼저 남깁니다
14. **안전한 종료**: 창을 닫아도 서버를 강제 종료하지 않습니다. `stop`으로 저장한 뒤 정지하고 앱을 닫습니다
15. **오류를 쉬운 말로 번역**: 포트 사용 중, 메모리 부족·과다 할당, Java 버전 불일치, 버전이 맞지 않는 플러그인, 빠진 의존성, Fabric 모드 충돌을 잡아냅니다. "이 플러그인이 현재 버전과 맞지 않아요 → 비활성화할까요?"처럼 해결 버튼과 함께 안내합니다
16. **업데이트 시 호환성 경고**: 버전을 올리기 전에 Modrinth에서 새 버전에 맞는 파일이 없는 플러그인·모드를 알려줍니다. 업데이트하면 맞는 것은 새 파일로 바꾸고, 안 맞는 것은 꺼 둡니다. 업데이트 전에 월드를 자동으로 백업합니다
17. **기존 서버 가져오기**: 앱 밖에서 만든 서버 폴더(Paper · Spigot · Bukkit · Purpur · Fabric · Forge · 바닐라)를 목록에 추가합니다. 새 서버 만들기 화면 위의 "기존 서버 가져오기"에서 폴더를 고르거나 끌어다 놓습니다.
   - 서버 jar, `server.properties`, 로그, `level.dat` 로 종류·버전·포트·월드를 알아내고, `start.bat` 등의 `-Xmx` 값으로 메모리를 채웁니다.
   - 복사(권장): 앱 데이터 폴더로 복사하고 원래 폴더는 그대로 둡니다. 그 자리에서 사용: 원래 폴더를 그대로 쓰고, 앱에서 삭제해도 폴더는 지우지 않습니다.
   - 원래 jar(예: `spigot-1.21.1.jar`)로 실행합니다. 기존 Paper 설정 파일은 바꾸지 않고, 자동 최적화는 JVM 옵션만 적용합니다.
   - Spigot·Bukkit 은 앱에서 업데이트하면 Paper 로 바뀝니다. NeoForge 서버는 아직 지원하지 않습니다.
18. **게임 규칙(gamerule)**: 설정 탭에서 인벤토리 유지, 몹 자연 스폰, 낮/밤 흐름, 날씨 변화, 몹의 블록 파괴 등을 켜고 끕니다. 월드 파일(`level.dat`)에 적힌 실제 규칙 이름을 읽으므로 버전마다 다른 이름(`keepInventory` / `keep_inventory`)도 맞춰 보여 주고, 설명이 없는 나머지 규칙은 "그 밖의 규칙"에 영문 이름으로 보여 줍니다. 켜져 있으면 `gamerule` 명령으로 바로 적용하고, 앱에서 정한 값과 난이도는 서버가 켜질 때마다 다시 맞춥니다. Bukkit·Paper 는 오버월드·네더·엔드가 각각 다른 월드라 규칙·난이도도 따로 저장되므로 `execute in <차원> run …` 으로 모든 월드에 보냅니다. 1.21.9 이후 게임 규칙으로 옮겨간 PVP·커맨드 블록도 같은 방식으로 적용합니다
19. **하이브리드 서버**: 플러그인과 Forge 모드를 함께 쓰는 서버입니다. Arclight(Forge 판)를 GitHub 릴리스에서 받아 실행하고, 첫 실행 때 Arclight 가 Forge 를 스스로 설치합니다. 플러그인·모드 탭에서 종류(플러그인 / Forge 모드)를 골라 Modrinth 에서 찾고, 파일로 추가하면 파일 안 정보로 `plugins/` 와 `mods/` 중 알맞은 곳에 넣습니다. 기존 Mohist·Arclight·Ketting·Magma·CatServer(Forge 기반) 폴더도 가져올 수 있습니다. NeoForge·Fabric 기반 하이브리드는 아직 지원하지 않습니다
20. **NeoForge 모드 서버**: 모드 서버의 로더로 NeoForge 를 고를 수 있습니다. NeoForge 저장소의 버전 목록에서 마인크래프트 버전에 맞는 빌드(정식 우선)를 골라 설치 프로그램으로 설치하고, 설치된 인자 파일로 실행합니다. 1.20.1 은 예전 이름(`net.neoforged:forge`)으로 나온 빌드를 쓰고, 이 버전에서는 Forge 모드도 검색·설치됩니다. 1.20.2 부터는 NeoForge 전용 모드만 받습니다. 기존 NeoForge 서버 폴더도 가져올 수 있습니다

## 디자인

MCES는 SCRF 메인 시스템([PR-SCRF](https://github.com/plugye980/PR-SCRF))에서 서버 관리 기능을 떼어 만든 단말이라는 설정으로, 메인 시스템의 화면 형식을 따릅니다.
규칙은 `design/THEME.md`, 값은 `src/renderer/tokens.css`(같은 값의 `design/tokens.json`)에 있습니다.
- 배경은 메인 시스템과 같은 렌더러로 그린 삼각 타일 벽입니다(`src/renderer/scene.js`). 빛 번짐, 화면 가장자리 색수차·블러, 비네트, 낟알, 마우스에 따른 기울기가 들어 있습니다
- 위쪽 꺼진 띠의 바닥면에 서버 수와 PC 사양을 새깁니다
- 왼쪽 위 MCES 로고와 단말 번호(기기마다 다른 4자리)는 위쪽 띠처럼 곡률을 준 채 켜진 계단 위에 그립니다. 오른쪽 위에는 앱 버전(`MC.ES-1.2.0`)이 나옵니다
- 서버 페이지의 배경은 서버마다 다르게 만들어지고, 육각형 덩어리로만 짜서 뾰족한 칸이 생기지 않습니다
- 켜면 패널이 켜지며 구동합니다(오류 있음 / 없음 두 가지). 화면을 바꿀 때는 UI가 흐려지며 사라지고, 배경 패널이 새 배치로 재정렬된 뒤 새 UI가 나타납니다. 서버를 만들 때만 패널이 칸마다 로딩 화면으로 넘어갑니다
- 테마를 바꾸면 버튼 자리에서 가까운 패널부터 하나씩 깜빡이며 천천히 새 색으로 바뀝니다. UI 창은 그동안 함께 천천히 색이 섞이며 바뀌고, 창 제목 줄 색은 패널이 다 바뀐 뒤에 바뀝니다. 바뀌는 도중에 여러 번 눌러도 마지막으로 고른 테마로 끝까지 바뀝니다
- 서버 만들기 버튼은 EULA에 동의하기 전에는 색이 빠지고 무늬가 옅으며, 동의하면 코발트 유리로 돌아옵니다
- 로딩 화면은 테마를 따릅니다(밝게면 흰 화면). 가운데는 고른 서버 종류의 MCES 로고입니다
- 홈은 왼쪽에 서버 만들기 버튼과 내 서버 목록(1:7), 오른쪽에 만들기 설정이 있습니다. 목록에서 서버를 고르면 그 서버만 보이는 페이지로 가고, 뒤로 나가기로 홈에 돌아옵니다
- 판은 공간 속에 비스듬히 섭니다. 모서리 꺾쇠, 바닥 그림자, 번호 탭, 코발트 박스, 상태 위젯, 시작 줄은 메인 시스템 형식입니다
- 숫자·코드·주소·콘솔은 고정폭입니다
- 메인에서 ESC를 누르면 종료 확인 뒤 UI가 내려가고 패널이 가장자리부터 차례로 꺼진 다음 앱이 닫힙니다(켜진 서버는 저장하고 끕니다). 서버 페이지에서 ESC는 뒤로 가기입니다
- 메인의 내 서버 목록에서 오른쪽 ✕로 서버를 지울 수 있습니다(꺼진 서버만)
- 밝게/어둡게를 모두 지원합니다. 어둡게는 메인 시스템의 꺼진 화면 값으로 만들었습니다

## 알아둘 점
- playit.gg 에이전트는 **v1.0.10** 데몬을 서비스로 설치하지 않고 앱 안에서 직접 실행합니다(`--secret-path`). v0.17.x로는 playit이 터널 자동 생성을 `AgentVersionTooOld`로 거절합니다. 계정 연결, 터널 만들기, 주소 조회는 playit API를 직접 호출합니다. 브라우저에서 승인하면 에이전트가 바로 켜지고 앱 창이 앞으로 돌아옵니다. 터널은 서버 포트로 자동 설정되고, 웹에서 직접 만든 터널도 로컬 포트가 같으면 그대로 씁니다.
- macOS용 playit 단독 실행 파일은 배포되지 않습니다. macOS에서는 playit.gg 앱을 따로 설치한 뒤, 주소 옆 ✎ 버튼으로 주소를 직접 넣어 주세요.
- 외부 접속 점검은 공개 서비스(mcsrvstat.us)를 쓰므로 결과가 1~2분 늦을 수 있습니다.
- 앱 밖에서 직접 넣은 플러그인·모드 jar도 목록에 보이고 켜고 끌 수 있습니다. 다만 업데이트 호환성 검사는 Modrinth로 설치한 것만 가능합니다.
