# 형태 없는 결 — 레시피

`tokens.css`(또는 `tokens.json`)와 이 문서 두 개만 있으면 다른 프로젝트에서
같은 인상을 다시 만들 수 있습니다. 페이지 코드는 필요 없습니다.

---

## 0. 원칙 세 줄

1. **바탕은 무채색.** 색은 값이 바뀌는 지점, 지금 조작 중인 요소, 읽어야 할 숫자에만.
2. **테두리를 쓰지 않는다.** `border`와 `outline`은 0. 구분이 필요하면 단차로 가른다.
3. **빛은 언제나 위에서.** 떠 있는 것은 윗면이 밝고 아래에 그늘, 파인 것은 그 반대.
   이 방향은 글자·판·조작 요소·그래프 전부에 같이 적용된다.

---

## 1. 단차 — 이 다섯 줄이 전부

| 상태 | 값 | 쓰는 곳 |
| --- | --- | --- |
| 올라옴 | `0 3px 7px var(--lo), 0 -1px 1px var(--hi)` | 손잡이, 분할 선택의 바탕, 계단의 판 |
| 크게 올라옴 | `0 14px 28px var(--lo), 0 -1px 2px var(--hi)` | 큰 카드가 필요할 때만 |
| 내려감 | `inset 0 3px 7px var(--inset-lo), inset 0 -2px 3px var(--hi), inset 0 17px 20px -15px var(--inset-lo)` | 그래프 판, 기둥 판 |
| 얕게 내려감 | `inset 0 2px 5px var(--inset-lo), inset 0 -1px 2px var(--hi)` | 레일 홈, 스위치 트랙, 눌린 칸 |
| 눌림 | `inset 0 3px 6px var(--lo-strong), inset 0 -1px 2px var(--hi)` | 손잡이를 잡고 있을 때 |

세 번째 줄의 `inset 0 17px 20px -15px`가 **2단 턱**이다. 이게 없으면 파인 면이 한 겹으로만 보인다.

**글자의 단차** — `filter: drop-shadow(0 -1px 0 var(--hi)) drop-shadow(0 3px 6px var(--lo))`.
작은 글자는 뒤쪽을 `0 2px 4px`로. `text-shadow`가 아니라 `filter`를 쓰는 이유는
글자에 그라디언트(`background-clip: text`)를 함께 쓰기 때문이다.

**항목을 가르는 결** — 상자 대신 한 줄. 어두운 1px 위에 밝은 1px을 겹치고 양 끝을 지운다.

```css
background-image: var(--edge);      /* 어두운 결 + 밝은 결, 양 끝 8%는 투명 */
background-size: 100% 1px, 100% 1px;
background-position: 0 0, 0 1px;
background-repeat: no-repeat;
```

## 2. 능선 — 그래프의 핵심

같은 경로를 네 번 그린다. **순서가 곧 입체감이다.**

| 순서 | 이름 | 색 | 굵기 | 변형 |
| --- | --- | --- | --- | --- |
| 1 | 면 | `--face-a` → `--face-b` (세로 그라디언트) | — | — |
| 2 | 그늘 | `--ridge-shade` | 8 | `translate(2px, 6px)` + `blur(4.5px)` |
| 3 | 빛 | `--ridge-lit` | 1.8 | `translateY(-1.7px)` |
| 4 | 선 | `--r1 → --r2 → --r3` (가로 그라디언트) | 2.4 | — |

- 3번을 4번보다 먼저 그려야 선 **위쪽에만** 빛이 얇게 남는다.
- 선 색이 가로로 흐르므로 위치마다 색이 다르다. 세로 인디케이터 대신
  `stroke-dasharray`로 몇 마디만 `--d1/--d2/--d3`(같은 색 계열, 한 단 낮은 명도)로 덧그린다.

**계단(2~4단)** — 위 순서를 단마다 반복하되 면색은 거의 같게 두고 **끝선만** 진하게 한다.

| 이름 | 색 | 굵기 | 변형 |
| --- | --- | --- | --- |
| 면 | `--tier-1` / `--tier-2` / `--tier-3` | — | — |
| 그늘 | `--ridge-shade` (opacity 0.5) | 6 | `translate(1.5px, 4px)` + `blur(4px)` |
| 끝선 | `--tier-edge` | 1.4 | — |
| 빛 | `--ridge-lit` (opacity 0.3) | 1.1 | `translateY(-1.4px)` |

단 사이 높이 차는 **11~26px**로 흔들어 평행하지 않게 한다. 일정한 간격은 계단으로 보이지만
어긋난 간격은 지형으로 보인다. 단의 면색 차이는 1~2%면 충분하다 — 더 벌리면 탁해진다.

## 3. 나머지 요소

**기둥** — 세로 그라디언트(색 100% → 6%)에 `drop-shadow(2px 9px 10px var(--lo-strong))`.
꼭대기는 흐리지 않게 둔다. 최고값 하나만 `--col-acc`.

**원호 게이지** — 홈을 세 겹으로 새긴다.
`track-lit`(`--hi-strong`, 9, `translateY(2.4px)`) → `track-shade`(`--lo-strong`, 9, `translateY(-2.2px)`, `blur(1px)`) → `track`(`--groove`, 7).
값 호는 발광 3단: `drop-shadow(0 0 4px) drop-shadow(0 0 10px) drop-shadow(0 0 20px)`, 색은 `--sky-glow`.
밝은 배경에서는 알파를 0.5 이상으로 올려야 보인다.

**조작 요소** — 만질 수 있는 것은 올라오고(`--raise`), 값이 담기는 곳은 내려간다(`--inset-sm`).
누르면 `--press`. 분할 선택은 바탕이 올라오고 **고른 칸만** 내려간다.
슬라이더 손잡이는 가운데 점 없이 포인트 색으로 채운 원 하나 + `0 0 12px var(--sky-glow)`.

**표** — 괘선 없이 정렬과 간격으로. 머리글 아래와 각 행 위에 §1의 결 한 줄만.
추세는 행마다 작은 능선(면 + 끝선의 빛 + 그늘)으로, 큰 그래프와 같은 어법.

**색수차** — 글자에는 쓰지 않는다. 그래프의 면과 게이지 호에만 SVG 필터로 아주 옅게.
원본을 ±1.1 옮겨 하늘색/황동색으로 물들인 뒤 알파 0.34로 밑에 깐다.

## 4. 글자

- 제목은 400~500, 본문은 300. 한글과 라틴이 같은 골격(Pretendard)을 쓰고 자간을 조금 연다.
- **모든 글자에 그라디언트**를 준다. 같은 색 안에서 농도만 내려가는 정도(`--text-a → --text-b`).
  `background-image` + `background-clip: text` + `-webkit-text-fill-color: transparent`.
- 포인트 색을 **글자에 쓸 때는 따로 어두운 값**(`--sky-text`, `--brass-text`)을 쓴다.
  면·마크용 밝은 색(`--sky`, `--brass`)을 작은 글자에 그대로 쓰면 대비가 3:1 아래로 떨어진다.

## 5. 포팅 체크리스트

- [ ] `border`와 `outline`을 전역에서 0으로 막았는가
- [ ] 모든 그림자가 **같은 방향**(위에서 오는 빛)인가
- [ ] 색이 세 곳(값이 바뀌는 지점 / 조작 중인 요소 / 읽어야 할 숫자)에만 있는가
- [ ] 파인 면에 2단 턱이 들어갔는가
- [ ] 계단의 면색 차이는 얕고, 끝선만 진한가
- [ ] 단 간격이 일정하지 않고 어긋나 있는가
- [ ] 글자용 포인트 색을 따로 썼는가 (대비 4:1 이상)
- [ ] 두 모드에서 같은 세기로 보이는가 (다크의 그늘 알파는 라이트보다 커야 같아 보인다)
