# MCES 테마 — SCRF 파생 단말

MCES는 SCRF 메인 시스템에서 서버 관리 기능을 떼어 만든 단말입니다.
색·서체·삼각 타일·문구 규칙은 메인 시스템([PR-SCRF](https://github.com/plugye980/PR-SCRF)의 `design/DESIGN.md`)을 그대로 따르고,
화면 배치와 구성 요소는 서버 관리에 맞게 따로 짰습니다.

값은 `src/renderer/tokens.css`(실제로 쓰는 파일)와 `design/tokens.json`(같은 값, Figma 등에서 사용)에 있습니다.

---

## 1. 메인 시스템에서 그대로 가져온 것

- **색:** 차가운 흰 바탕, 코발트 `#1f3cff`, 차가운 회색, 금색 `#c49a3c`(점·선 수준). 경고는 금색, 거부·실패는 어두운 자주(`#9a3a4c`).
- **서체:** Pretendard Variable(제목 800, 자간 −0.02em) + 고정폭(숫자·코드·주소·로그).
- **삼각 타일:** 한 변 120px, 켜짐 +44 / 대기 / 꺼짐 −28, 원근 `z × 0.0022` 퍼짐·`z × 0.36` 들림, 빛은 위·살짝 왼쪽.
- **문구:** `[태그] 항목 : 값`, 로그 머리 `[ OK ]` `[ .. ]` `[WARN]` `[ERR ]`, 이모지 없음.
- **테두리 없음, 판 그림자는 한 겹.**

## 2. MCES에서 바꾼 것

| 메인 시스템(시작 화면) | MCES |
|---|---|
| 왼쪽 비스듬한 판 + 번호 탭 01~05 + 오른쪽 로고 | 왼쪽 서버 목록 판 + 오른쪽 서버 상세. 판은 기울이지 않는다(클릭 정확도) |
| 상·하단 곡면 바 | 아래쪽 한 줄 상태 줄(`[MCES ROUTE] 단말 상태 : …` + PC 사양) |
| 큰 번호 탭(28px 번호, 위에 선) | 바탕선 위의 글자 탭. 앞에 작은 고정폭 번호, 고른 탭만 코발트 2px **밑줄** |
| 정사각 코발트 박스 | 가로로 긴 코발트 띠(접속 주소). 유리 조각 각도를 띠에 맞게 바꿈 |
| 일출·일몰 반원 게이지 | 270° 눈금 홈 게이지(TPS·메모리·CPU) |
| 마우스 기울기·가장자리 렌즈·글리치 구동 | 없음. 배경은 정적이고 창 크기·테마가 바뀔 때만 다시 그린다 |

**로딩(구동 연출)은 아직 넣지 않았습니다.** 넣을 때는 메인 시스템 규칙(배경 패널 점등 → UI 글리치 등장 순서, 글리치는 켜질 때·바뀔 때·오류 때만)을 따릅니다.

## 3. 화면 구성

- **배경(`backdrop.js`):** 오른쪽 아래 모서리 기준으로 켜진 계단 + 그 옆 꺼진 홈. 위쪽(서버 이름·버튼)과 왼쪽(서버 목록)은 비워 둔다. 맨 위 110px 띠에는 X자를 두지 않는다.
- **서버 목록 판:** 브랜드(`MCES`, 자간 0.42em) → `내 서버` + 개수 → 서버 줄(고정폭 번호 · 이름 · 상태 점 · TPS) → 새 서버 만들기 → 테마.
  고른 서버는 옅은 코발트 면 + 왼쪽 2px 코발트 선.
- **머리:** 고정폭 코드 줄(`SV-01 · PAPER #231 · PORT 25565`) → 서버 이름 → 상태 칩(짙은 바탕) + 종류·버전.
- **코발트 면은 화면당 하나:** 서버 화면은 접속 주소 띠, 만들기 화면은 고른 서버 종류 카드.
  그 밖의 주 동작은 흰 면 + 코발트 글자 + 코발트 밑줄. 화면의 첫째 동작(켜기, 서버 만들기)만 코발트로 채운다.
- **콘솔:** 꺼진 패널 화면(`#04060a`) 위의 글자, 옅은 주사선. 라이트 테마에서도 같다.
- **그래프:** 꺼진 바닥 위 삼각 격자, 옅은 코발트 면 + 코발트 선, 지금 값 점, 할당 한도는 금색 점선 하나.
- **알림·토스트:** 왼쪽 3px 색 막대 + 로그 머리(`[WARN]` `[ERR ]` `[ OK ]`).
- **창(모달):** 흰 판, 왼쪽 위·오른쪽 아래 코발트 꺾쇠.

## 4. 조작 요소

| 요소 | 생김새 |
|---|---|
| 입력칸 | 옅은 면 + 1px 밑줄, 누르면 코발트 2px 밑줄 |
| 분할 선택 | 옅은 홈 안에서 고른 칸만 흰 면 + 코발트 밑줄 |
| 스위치 | 모서리 3px 사각 트랙 + 사각 손잡이, 켜지면 코발트 |
| 체크 | 18px 사각, 켜지면 코발트 |
| 슬라이더 | 3px 막대 + 코발트 마름모, 추천값 표시는 금색 |
| 진행 막대 | 3px 코발트 |
| 상태 점 | 켜짐 = 코발트, 꺼짐 = 회색 고리, 실패 = 어두운 자주, 진행 중 = 금색 깜빡임 |

## 5. 다크 테마

메인 시스템은 밝은 공간만 정의하므로, MCES의 어둡게는 메인 시스템의 **꺼진 화면** 값(`#04060a`, 선 `rgba(120,150,180,.13)`, 글자 `#d9e4f0`)으로 만들었습니다.
코발트는 어두운 바탕에서 읽히도록 `#5b78ff`(글자는 `#8fa8ff`)를 씁니다.

## 6. 체크리스트

1. 바탕은 차가운 흰색인가 (다크는 꺼진 화면색)
2. 입체감은 배경 타일이 맡고, 판 그림자는 한 겹인가
3. 코발트 면이 화면에 하나인가
4. 금색은 점·선 수준인가
5. 숫자·코드·주소는 고정폭이고, 한글이 섞인 값은 본문 서체인가
6. 테두리를 쓰지 않았는가
7. 평소 화면에 반복 애니메이션이 없는가 (진행 중 상태 점만 예외)
