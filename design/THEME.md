# MCES 테마 — SCRF 파생 단말

MCES는 SCRF 메인 시스템에서 서버 관리 기능을 떼어 만든 단말입니다.
색·서체·삼각 타일·문구 규칙은 메인 시스템([PR-SCRF](https://github.com/plugye980/PR-SCRF)의 `design/DESIGN.md`)을 그대로 따르고,
화면 배치와 구성 요소는 서버 관리에 맞게 따로 짰습니다.

값은 `src/renderer/tokens.css`(실제로 쓰는 파일)와 `design/tokens.json`(같은 값, Figma 등에서 사용)에 있습니다.

---

## 0. 방향 — 눈이 편한 단말

쓰는 사람의 평가("너무 화려하다")에 따라 메인 시스템의 연출을 덜어 냈습니다. SCRF의 정체성(삼각 그리드, 모서리 꺾쇠, 번호 탭, 코발트 포인트, 고정폭 코드)은 남기고,
오래 보면 피곤한 것(입체 타일 벽, 판 기울기, UI 위의 블러·렌즈 효과, 글리치, 배경 재정렬, 테마 물결)은 뺐습니다. **글자에는 어떤 블러도 걸지 않습니다.**

배경 요소의 클래스 이름은 모두 `bg-` 로 시작합니다(UI의 `.grid` 같은 이름과 겹치면 배경 필터가 UI에 걸린다).

## 1. 메인 시스템에서 그대로 가져온 것

- **색:** 차가운 흰 바탕, 코발트 `#1f3cff`, 차가운 회색, 금색 `#c49a3c`(점·선 수준). 경고는 금색, 거부·실패는 어두운 자주(`#9a3a4c`).
- **서체:** Pretendard Variable(제목 800, 자간 −0.02em) + 고정폭(숫자·코드·주소·로그).
- **삼각 그리드:** 한 변 120px. 선은 연하게, 꼭짓점의 X자만 진하게. 밝게 테마의 바탕은 푸른 기를 더한 옅은 흰색(`#f4f7fc` → `#eaf0f8`).
- **문구:** `[태그] 항목 : 값`, 로그 머리 `[ OK ]` `[ .. ]` `[WARN]` `[ERR ]`, 이모지 없음.
- **테두리 없음, 판 그림자는 한 겹.**

## 2. 화면 형식

| 항목 | 내용 |
|---|---|
| 배경 | `src/renderer/scene.js` — 흰 삼각 그리드 공간(white-grid 형식). 푸른 기가 아주 살짝 섞인 흰 바탕, 연한 선 + 진한 X자, 선 자체의 빛 번짐, 천천히 떠도는 빛 덩어리 셋 |
| 렌즈(배경에만) | 맨 가장자리의 옅은 색수차(SVG 필터, 2px 안팎) → 가장자리 블러 → 전체 빛 번짐. UI 판 아래 층이라 글자에는 걸리지 않는다 |
| 렌즈(화면 전체) | 옅은 비네트, 낟알 0.02 |
| 마우스 | 배경만 최대 0.8°·0.6° 기운다. 판과 글자는 움직이지 않는다. 마우스가 멈추면 계산도 멈춘다 |
| 머리글 | 왼쪽 위 로고(코발트 유리 표시 + `MCES` + `SERVER TERMINAL · 0x____`), 오른쪽 위 앱 버전(`MC.ES-x.y.z`, 금색 세로줄)과 서버 수·PC 사양 |
| 판 | 평평하게 선다(3D 기울기를 쓰면 스크롤되는 글자가 흐려진다). 바탕 0.94로 배경이 덜 비친다. 모서리 꺾쇠 두 개, 판 아래 바닥 그림자 |
| 번호 탭 | 위에 1px 선, 고정폭 번호 + 이름. 고른 탭만 코발트 2px |
| 코발트 박스 | 조각을 줄인 차분한 코발트 유리 위에 큰 제목 · 상태 줄. 글자 빛남 없음 |
| 상태 위젯 | 라벨 + 고정폭 값 + 3px 막대, 위에 옅은 선 |
| 시작 줄 | 큰 글자 + 키 표시 + 코발트 밑줄·화살표 |

창이 뒤로 가면(다른 창을 보거나 게임 중) 떠도는 빛과 낟알을 멈춰 그래픽 자원을 양보한다.

## 2-1. 구동 · 화면 전환 · 로딩

**배경은 그대로 두고 UI만 부드럽게 오르내린다.**

- **구동:** 배경과 머리글이 떠오르고(0.9초), 그 위로 판이 아래에서 부드럽게 올라온다(1초).
- **홈 ↔ 서버 페이지:** 판이 아래로 내려가며 사라지고(0.45초) 새 판이 올라온다(0.7초). 배경 재정렬은 없다.
- **서버 만들기 · 가져오기:** 판이 내려간 뒤 로딩 화면이 배경 위로 부드럽게 겹치고(0.45초), 끝나면 걷히며 서버 페이지가 올라온다.
- **로딩 화면:** 천궁 로더를 SCRF 색으로 옮겨 그린다(`scene.js`의 `drawLoader`). 배경 그리드를 옅게 덮은 위에 신성 기하학 고리, 빛 알갱이, 빛의 띠, 원판과 금색 모서리 눈금, 금색 궤도 안의 MCES 로고, 상태 문구, 3px 진행 막대(숫자 없음).
- **테마 전환:** 배경과 UI 색이 함께 0.9초에 걸쳐 섞인다. 색·숫자 토큰을 `@property`로 등록해 두고 전환하는 동안(`.theme-fade`)만 섞는다. 전환 중에 또 누르면 마지막 값만 기억했다가 잇는다. 창 제목 줄은 다 바뀐 뒤에.
- **종료:** 판이 아래로 내려가고 머리글이 걷힌 뒤 화면이 천천히 어두워지고 앱이 닫힌다.
- 운영체제의 "동작 줄이기"가 켜져 있으면 움직임을 모두 끈다.

## 3. 배치

- **머리글:** 높이 104px(`--band-bottom`). 판은 이 아래에서 시작한다.
- **홈(만들기 페이지):** 왼쪽 판을 위아래 1:7로 나눈다. 위는 코발트 "서버 만들기"(가져오기 모드에서는 "서버 가져오기") 버튼과 그 아래 EULA 동의, 아래는 내 서버 목록(번호 01, 02 …). 오른쪽 판은 만들기 설정(서버 종류·확인·버전·기본 설정·맵·EULA) 또는 가져오기 설정.
  목록에서 서버를 누르면 로딩을 거쳐 그 서버 페이지로 간다.
- **서버 페이지:** 판 하나의 큰 창(좌우로 기울이지 않고 위쪽만 살짝 물러남). 왼쪽 칸은 뒤로 나가기 → 코발트 박스(이름·코드·접속 주소·점검) → 설명 한 줄 → 상태 위젯(접속·TPS·메모리·CPU) → 시작 줄(서버 켜기/끄기) → 다시 켜기·업데이트·삭제. 오른쪽 칸은 번호 탭(개요·콘솔·접속자·플러그인·백업·설정 — 고르지 않은 탭은 칸 명도를 낮춘다) → 오류 안내 → 내용. 뒤로 나가기를 누르면 홈으로 돌아간다.
- 맨 아래에 테마(밝게/어둡게).
- 판은 띠 바로 아래에서 시작한다. 띠의 위치는 `scene.js`가 `--band-top`·`--band-bottom`으로 알려 준다.
- **코발트 면은 화면당 하나:** 서버 페이지는 서버 박스, 홈은 서버 만들기 버튼. 고른 서버 종류는 옅은 코발트 면 + 2px 선.
- **콘솔:** 꺼진 패널 화면(`#04060a`) 위의 글자, 옅은 주사선.
- **알림·토스트:** 왼쪽 3px 색 막대 + 로그 머리(`[WARN]` `[ERR ]` `[ OK ]`). 창(모달)은 판과 같은 바탕에 모서리 꺾쇠.

## 4. 조작 요소

| 요소 | 생김새 |
|---|---|
| 입력칸 | 옅은 면 + 1px 밑줄, 누르면 코발트 2px 밑줄 |
| 분할 선택 | 옅은 홈 안에서 고른 칸만 흰 면 + 코발트 밑줄 |
| 스위치 | 모서리 3px 사각 트랙 + 사각 손잡이, 켜지면 코발트 |
| 체크 | 18px 사각, 켜지면 코발트 |
| 슬라이더 | 3px 막대 + 코발트 마름모, 추천값 표시는 금색 |
| 진행 막대 | 3px 코발트 |
| 상태 점 | 켜짐 = 코발트, 꺼짐 = 회색 고리, 실패 = 어두운 자주, 진행 중 = 금색 깜빡임 |

## 5. 다크 테마

메인 시스템은 밝은 공간만 정의하므로, 어둡게는 같은 그리드 공간을 **부드러운 남색 검정**(`#141a25` → `#0d1119`) 위에 옮겼습니다. 순수한 검정보다 대비가 덜해 눈이 편합니다.
선과 X자는 밝은 회청색을 낮은 불투명도로, 떠도는 빛은 옅은 푸른빛으로. 코발트는 `#5b78ff`(글자는 `#8fa8ff`).

## 6. 체크리스트

1. 바탕은 차가운 흰색인가 (다크는 부드러운 남색 검정)
2. 깊이는 배경 공간이 맡고, 판의 기울기·움직임은 작게 두었는가
3. 코발트 면이 화면에 하나인가
4. 금색은 점·선 수준인가
5. 숫자·코드·주소는 고정폭이고, 한글이 섞인 값은 본문 서체인가
6. 테두리를 쓰지 않았는가
7. 평소 화면의 반복 움직임은 배경의 느린 빛 덩어리와 진행 중 상태 점뿐인가
8. 흐린 안내 글자도 바탕과 대비 4.5:1 이상인가
