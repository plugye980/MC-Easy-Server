# MCES 테마 — SCRF 파생 단말

MCES는 SCRF 메인 시스템에서 서버 관리 기능을 떼어 만든 단말입니다.
색·서체·삼각 타일·문구 규칙은 메인 시스템([PR-SCRF](https://github.com/plugye980/PR-SCRF)의 `design/DESIGN.md`)을 그대로 따르고,
화면 배치와 구성 요소는 서버 관리에 맞게 따로 짰습니다.

값은 `src/renderer/tokens.css`(실제로 쓰는 파일)와 `design/tokens.json`(같은 값, Figma 등에서 사용)에 있습니다.

---

## 1. 메인 시스템에서 그대로 가져온 것

- **색:** 차가운 흰 바탕, 코발트 `#1f3cff`, 차가운 회색, 금색 `#c49a3c`(점·선 수준). 경고는 금색, 거부·실패는 어두운 자주(`#9a3a4c`).
- **서체:** Pretendard Variable(제목 800, 자간 −0.02em) + 고정폭(숫자·코드·주소·로그).
- **삼각 타일:** 한 변 120px, 켜짐 +44 / 대기 / 꺼짐 −28, 원근 `z × 0.0022` 퍼짐·`z × 0.36` 들림, 빛은 위·살짝 왼쪽.
- **문구:** `[태그] 항목 : 값`, 로그 머리 `[ OK ]` `[ .. ]` `[WARN]` `[ERR ]`, 이모지 없음.
- **테두리 없음, 판 그림자는 한 겹.**

## 2. 화면 형식 — 메인 시스템과 같게

| 항목 | 내용 |
|---|---|
| 장면 | `src/renderer/scene.js` — PR-SCRF `start.js`의 렌더러를 옮긴 것. 삼각기둥 옆면·그림자·구멍 그늘, 바닥 그리드와 X자, 빛 번짐, 화면 가장자리 색수차(R·G·B를 서로 다른 배율로 벌림)와 블러 |
| 렌즈 층 | 비네트(마우스 반대쪽으로 2.5% 기우는 중심), 낟알(작은 노이즈 그림을 한 번 만들어 깔기) |
| 마우스 | 장면은 최대 0.8°·0.6°, 판은 ±3° 더 기운다. 마우스가 움직일 때만 다시 그린다 |
| 공간에 새긴 UI | 둘째 줄의 꺼진 띠 바닥면에 코드(`MC.ES-0.7`)와 서버 수·PC 사양을 곡면으로 붙인다 |
| 판 | 왼쪽 판 `rotateY(13°)`(바깥쪽 끝이 앞으로), 오른쪽 판 `rotateY(−14°)`. 모서리 꺾쇠 두 개, 판 아래 바닥 그림자, 테두리 없음 |
| 번호 탭 | 위에 1px 선, 고정폭 번호 + 이름. 고른 탭만 코발트 2px |
| 코발트 박스 | 유리 조각 그라데이션 위에 짙은 칩 · 큰 제목 · 상태 줄 |
| 상태 위젯 | 라벨 + 고정폭 값 + 3px 막대, 위에 옅은 선 |
| 시작 줄 | 큰 글자 + 키 표시 + 코발트 밑줄·화살표 |

장면은 기준 화면(가로 2560)으로 그린 뒤 창 크기에 맞게 줄인다(최소 0.6배). 창이 작아도 같은 구도가 나오고, 띠의 글자는 줄인 만큼 키워서 실제 크기를 지킨다.

## 2-1. 구동 · 화면 전환 · 로딩

PR-SCRF의 화면 전환 구조를 따른다: **UI가 흐려지며 사라짐 → 배경 패널 재정렬 → 새 UI가 흐림이 걷히며 등장.** 글자는 언제나 배경이 다 바뀐 뒤에 나온다.

- **구동:** 앱을 켜면 누르지 않아도 검은 화면에서 패널이 묶음 단위로 켜진다. 오류 있음 / 없음 둘 중 하나를 무작위로 고른다. 글리치 등장은 이때 한 번만.
  - 오류 없음: 깜빡임 없이 빠르게 켜지고 UI는 흐림→선명 페이드
  - 오류 있음: 불안정한 점등, 색이 갈라지거나 엉뚱한 자리를 비추는 패널, 화면이 찢어지는 줄, 구동 로그의 `[WARN]`·`[ERR ]` 1~3줄, UI 글리치 등장
  - 왼쪽 아래 패널 몇 장에 구동 로그(`C:\MCES> link --host CORE …`)가 뜨고, 로그가 끝나면 그 패널도 켜진다
- **홈 ↔ 서버 페이지:** 로딩 없이. 판이 흐려지며 사라지고(0.6초) → 패널이 가운데에서 바깥으로, 불규칙한 묶음으로 새 배치로 바뀌고(꺼짐↔켜짐은 대기를 거친다) → 판이 나타나며 줄마다 70ms씩 늦게 옆에서 미끄러져 들어온다.
- **서버 만들기 · 가져오기:** 판이 사라진 뒤 패널이 꺼지지 않고, 칸마다 채널이 바뀌듯 로딩 화면으로 넘어간다. 끝나면 같은 방식으로 서버 페이지 배치의 배경으로 넘어온다.
- **로딩 화면:** 천궁 로더를 SCRF 색으로 옮겨 패널 화면에 그린다(`scene.js`의 `drawLoader`). 신성 기하학 고리, 떠오르는 빛 알갱이, 가로지르는 빛의 띠, 파인 원판과 금색 모서리 눈금, 금색 궤도 안의 **MCES 로고(코발트 유리 네모 + 고른 서버 종류의 흰 모양 — 왼쪽 위 로고와 같은 그림)**, 밝게 테마에서는 흰 로딩 화면, 상태 문구, 3px 진행 막대(숫자 없음). 막대는 실제 진행을 따라 차오르고 한 번에 뛰지 않는다. 진행 소식이 없으면 92%까지 아주 천천히 찬다.
- **테마 전환(새로 고침):** 테마 버튼 자리에서 부드러운 원으로 새 색이 번지고, 파면이 지나가는 칸이 잠깐 밝아진다. 캔버스는 다시 만들지 않고 색만 바꾼다. UI 쪽 색 토큰은 `@property`(`<color>`)로 등록해 두고, 전환하는 동안(`.theme-fade`) 1.5초에 걸쳐 섞는다. 배경 장면은 `:root` 값을 바로 읽으므로 섞이지 않는다. 전환 중에 또 누르면 마지막 값만 기억했다가 지금 전환이 끝난 뒤 잇는다. 창 제목 줄은 다 바뀐 뒤에.

## 3. 배치

- **타일:** 모서리 기준으로 적는다(`scene.js`의 `LAYOUT`). 묶음마다 기준 칸의 짝(`par`)을 맞춰 창 크기가 바뀌어도 삼각형 방향이 뒤집히지 않는다.
  - 둘째 줄: 왼쪽 7칸을 뺀 나머지가 길게 꺼진 띠
  - 왼쪽 위: 띠 왼쪽에서 아래로 내려오는 켜진 계단 — 로고가 이 위에 선다
  - 오른쪽 위: 띠 오른쪽 끝에서 오른쪽 아래로 내려가는 켜진 사선, 맨 윗줄 가운데쯤 켜진 조각
  - 왼쪽 아래 켜진 사선 묶음, 오른쪽 아래 작은 켜진 조각 둘
- **로고:** 왼쪽 위, 띠 높이 가운데. 코발트 유리 표시 + `MCES`(자간 0.42em).
- **배경 배치:** 홈은 위 그대로. 서버 페이지는 위쪽 띠와 왼쪽 계단만 남기고 나머지는 서버마다 다르다(서버 id로 정한 난수). 켜짐·꺼짐은 육각형(꼭짓점 하나를 둘러싼 6칸) 덩어리로만 놓아 외톨이 삼각형·톱니 같은 뾰족한 모양이 생기지 않는다. 덩어리끼리는 붙이지 않는다.
- **로고:** 왼쪽 위 켜진 계단 윗면에 위쪽 띠와 같은 곡률로 그린다(DOM이 아니라 장면 안). 표시는 지금 서버 종류 모양, 아래 줄은 `SERVER TERMINAL · 0x____` — 기기 이름·사용자·네트워크 주소로 만든 기기별 번호. 오른쪽 위 띠의 코드는 앱 버전(`MC.ES-1.2.0`).
- **홈(만들기 페이지):** 왼쪽 판을 위아래 1:7로 나눈다. 위는 코발트 "서버 만들기"(가져오기 모드에서는 "서버 가져오기") 버튼과 그 아래 EULA 동의, 아래는 내 서버 목록(번호 01, 02 …). 오른쪽 판은 만들기 설정(서버 종류·확인·버전·기본 설정·맵·EULA) 또는 가져오기 설정.
  목록에서 서버를 누르면 로딩을 거쳐 그 서버 페이지로 간다.
- **서버 페이지:** 판 하나의 큰 창(좌우로 기울이지 않고 위쪽만 살짝 물러남). 왼쪽 칸은 뒤로 나가기 → 코발트 박스(이름·코드·접속 주소·점검) → 설명 한 줄 → 상태 위젯(접속·TPS·메모리·CPU) → 시작 줄(서버 켜기/끄기) → 다시 켜기·업데이트·삭제. 오른쪽 칸은 번호 탭(개요·콘솔·접속자·플러그인·백업·설정 — 고르지 않은 탭은 칸 명도를 낮춘다) → 오류 안내 → 내용. 뒤로 나가기를 누르면 홈으로 돌아간다.
- 맨 아래에 테마(밝게/어둡게).
- 판은 띠 바로 아래에서 시작한다. 띠의 위치는 `scene.js`가 `--band-top`·`--band-bottom`으로 알려 준다.
- **코발트 면은 화면당 하나:** 서버 페이지는 서버 박스, 홈은 서버 만들기 버튼. 고른 서버 종류는 옅은 코발트 면 + 2px 선.
- **콘솔:** 꺼진 패널 화면(`#04060a`) 위의 글자, 옅은 주사선.
- **알림·토스트:** 왼쪽 3px 색 막대 + 로그 머리(`[WARN]` `[ERR ]` `[ OK ]`). 창(모달)은 판과 같은 바탕에 모서리 꺾쇠.

## 4. 조작 요소

| 요소 | 생김새 |
|---|---|
| 입력칸 | 옅은 면 + 1px 밑줄, 누르면 코발트 2px 밑줄 |
| 분할 선택 | 옅은 홈 안에서 고른 칸만 흰 면 + 코발트 밑줄 |
| 스위치 | 모서리 3px 사각 트랙 + 사각 손잡이, 켜지면 코발트 |
| 체크 | 18px 사각, 켜지면 코발트 |
| 슬라이더 | 3px 막대 + 코발트 마름모, 추천값 표시는 금색 |
| 진행 막대 | 3px 코발트 |
| 상태 점 | 켜짐 = 코발트, 꺼짐 = 회색 고리, 실패 = 어두운 자주, 진행 중 = 금색 깜빡임 |

## 5. 다크 테마

메인 시스템은 밝은 공간만 정의하므로, MCES의 어둡게는 메인 시스템의 **꺼진 화면** 값(`#04060a`, 선 `rgba(120,150,180,.13)`, 글자 `#d9e4f0`)으로 만들었습니다.
코발트는 어두운 바탕에서 읽히도록 `#5b78ff`(글자는 `#8fa8ff`)를 씁니다.

## 6. 체크리스트

1. 바탕은 차가운 흰색인가 (다크는 꺼진 화면색)
2. 입체감은 배경 타일과 판의 기울기가 맡고 있는가
3. 코발트 면이 화면에 하나인가
4. 금색은 점·선 수준인가
5. 숫자·코드·주소는 고정폭이고, 한글이 섞인 값은 본문 서체인가
6. 테두리를 쓰지 않았는가
7. 평소 화면에 반복 애니메이션이 없는가 (진행 중 상태 점만 예외)
